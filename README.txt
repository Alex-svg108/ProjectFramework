```
Созданы приложения users, materials.
Созданы модели User, Course, Lesson.
Модели перенесены в базу данных с помощью инструмента миграций.
Реализоаны CRUD для курса с использованием Viewsets, для урока - Generic-классы.
Для модели курса в сериализатор добавлено поле вывода количества уроков. Реализован с помощью
SerializerMethodField().
Добавлена новая модель в приложение users: Payments.
Настроена фильтрация для эндпоинта вывода списка платежей:
 - менять порядок сортировки по дате оплаты,
 - фильтровать по курсу или уроку,
 - фильтровать по способу оплаты.
Реализована регистрация пользователей.
Создана группа модераторов с правами работы с любыми уроками и курсами,
но без возможности их удалять и создавать новые.
Настроены права доступа для объектов, пользователи, которые не входят в группу модераторов,
могут видеть, редактировать и удалять только свои курсы и уроки.
Реализован вывод всех уроков и курсов.
Добавлена модель подписки.
Добавлена проверка отсутствия ссылок на сторонние ресурсы, отличные от youtube.com.
```
